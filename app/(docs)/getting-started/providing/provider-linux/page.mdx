# Providing to URnetwork

To share your internet with URnetwork, you'll need to run a small "provider" application on your computer. This software handles the connection between your system and the network.

We provide these applications for GNU/Linux, macOS, and Windows. This guide will help you get set up on Linux in just a few steps.

## GNU/Linux Setup

<Callout type="warning">
**Prerequisites**
Before starting, ensure your system has these basic tools installed:
 * [cURL](https://curl.se)
 * Either [jq](https://jqlang.org) or [Python 3.8+](https://python.org)
 * A standard terminal (POSIX-compatible shell)

If you aren't sure if you have these, you can run our [Install Helper script](https://raw.githubusercontent.com/urnetwork/connect/refs/heads/main/scripts/Provider_Install_Deps.sh) as a root user, or install them using your distribution's package manager.
</Callout>

### 1. Installation
Run this command in your terminal to install the provider and the **urnet-tools** helper:

```bash
curl -fSsL https://raw.githubusercontent.com/urnetwork/connect/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

### 2. Post-Install Setup
To make sure your system recognizes the new `urnetwork` commands, refresh your shell configuration:

```bash
source ~/.bashrc
```

<Callout type="info">
    **Not using Bash?** If you use a different shell (like Zsh or Fish), the installer will still create a `~/.bashrc` file. Simply copy the contents of that file into your specific shell profile.
</Callout>

To verify the installation worked, try running these help commands:
```bash
urnetwork --help
urnet-tools --help
```

### 3. Linking Your Account
You need to log in to connect your provider to your URnetwork account:

```bash
urnetwork auth
```

When prompted, enter your **Auth Code**. You can find this code in the settings section of the [UR.io dashboard](https://ur.io), the [Web App](https://app.ur.network), or the mobile app.



<img src="https://raw.githubusercontent.com/virtual-designer/urnetwork-docs/refs/heads/main/app/(content)/urio_auth.png" height="335px" width="576px" />

*Note: Your login token is saved privately at `~/.urnetwork/jwt`. Keep this file secure and do not share it.*

### 4. Starting the Provider
Now you are ready to start sharing your connection:

```bash
urnet-tools start
```

To ensure the provider starts automatically whenever your computer reboots, run:

```bash
urnet-tools auto-start on
```

### 5. Keeping the Connection Alive (Lingering)
On Linux, user-run applications often stop the moment you log out or close your terminal window. To keep your provider online 24/7, you must enable **lingering**:

```bash
loginctl enable-linger
```

Check your status with:
```bash
urnet-tools status
```
If everything looks good, you are now successfully contributing to URnetwork!

---

### Managing Your Provider

**Updating**
Keep your software up to date manually:
```bash
urnet-tools update
```
Or set it to update automatically every day:
```bash
urnet-tools auto-update on
```

**Uninstalling**
If you need to remove URnetwork from your system:
```bash
urnet-tools uninstall
```
